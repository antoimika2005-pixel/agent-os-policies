Privacy Policy

Effective August 23, 2026

Agent OS is a personal, self-hosted automation tool built and operated solely by its owner to create and publish original video content to social media accounts the owner personally controls. It is not a public service and is not distributed to other users — this policy describes how data is handled for exactly one person: its owner.

What data is processed

  • OAuth access and refresh tokens for connected accounts (YouTube, and TikTok via the Content Posting API), obtained through each platform's own official authorization flow and used exclusively to publish videos the owner has created.
  • Video, audio, and image files generated or uploaded by the owner for their own content.
  • Basic account metadata returned by each platform's API (e.g. channel or account name, profile thumbnail) needed to show which accounts are connected.

Where it lives

Everything above is stored locally, on the owner's own computer. OAuth tokens are encrypted at rest (AES-256-GCM) with a key generated on that machine. Nothing is uploaded to any server operated by, or on behalf of, Agent OS — the only network calls made with this data go directly to the platform APIs themselves (TikTok, YouTube, Google) to perform the publishing action the owner requested.

What is never done

  • No data is sold, rented, or shared with any third party for advertising, analytics, or any purpose unrelated to publishing the owner's own content.
  • No tracking, analytics, or telemetry is collected about end users — because there are none. The owner is the only user of this application.

Third-party processors

Media generation for the owner's own content may pass through third-party AI providers the owner has independently subscribed to and pays for (for example Kie.ai, FAL.ai, OpenRouter). These providers process only the content the owner creates, under their own respective terms, and are never given access to any connected social media account or credentials.

Retention & deletion

All data described above lives exclusively on the owner's local machine. Uninstalling Agent OS or deleting its local data folder permanently removes it. Disconnecting a platform account from within the app immediately revokes and deletes its stored tokens.
